Clean-Latent Prediction in Latent Diffusion Transformers

arXiv Paper GitHub Code

Flow matching with clean-data prediction has shown that regressing the clean point can exploit low-dimensional structure more effectively than predicting an ambient noised quantity. We ask whether this principle remains useful after images are mapped into a learned latent space.

We instantiate this comparison with JLT, a controlled 130M latent diffusion Transformer over frozen FLUX.2 VAE codes, and compare clean-latent prediction with a matched velocity-prediction DiT under the same representation, backbone, and training settings.

On ImageNet 256×256, JLT-B/1 obtains FID-50K 2.50 with classifier-free guidance, with a large matched-target gap over velocity prediction.

Method

Prediction Targets:

y_x = x,    y_ε = ε,    y_v = x - ε

For fixed t, these targets are algebraically equivalent via affine readout. However, with finite model capacity, the direct output learned by the network changes the difficulty of the regression problem.

Target-Geometry Analysis:

Cov(y_x) = Σ,    Cov(y_ε) = I,    Cov(y_v) = Σ + I

Key insight: Velocity prediction adds an isotropic unit floor to every clean-latent direction. When Σ is anisotropic, directions with little clean-data variation become unit-variance directions in yv, while clean prediction keeps their target variance small.

Key Findings

Target Geometry Matters

Clean-latent prediction consistently outperforms matched velocity prediction under fixed representation, architecture, and training settings.

Mechanism

Velocity prediction adds an isotropic covariance floor and amplifies low-variance latent directions, while clean prediction attenuates them.

Representation Independence

The advantage is not a byproduct of a particular patch size — it holds at both /1 and /2 VAE-grid scales.
